Shared library modules for the AI Image Gallery:

- `supabaseClient.ts` – browser Supabase client using public anon key.
- `supabaseServer.ts` – server-side Supabase client bound to Next.js cookies.
- `ai/*` – Google Vision client and image processing.
- `search/similarity.ts` – similarity helpers for tags/colors.
- `utils/*` – rgbToHex, descriptionFromLabels, etc.
